# office-replace

Excel / Word / PowerPoint のファイルを、置換表に従って **まとめて置換** するツールです。
資料の使い回しで社名・担当者名・年度を差し替えるときや、提出前に固有名を伏せるときに使います。

- **対象**: セルの文字列・図形（テキストボックス）・グラフのタイトル（Excel）／本文・表・ヘッダー・フッター・脚注・コメント・テキストボックス（Word）／
  スライドの図形・表・ノート・グラフ（PowerPoint）／**シート名**／**ファイル名**
- **ワイルドカード**: `*`（0 文字以上）と `?`（1 文字）。`~*` `~?` で記号そのもの。`--regex` で正規表現
- **安全**: 元のファイルは書き換えず、別のフォルダに出力。`--dry-run` で置換される箇所だけを確認できる
- **書式を保つ**: 書式の切れ目をまたぐ文字列も置換し、置換した範囲の外の書式は変えない。画像・マクロなど他の部品はそのまま
- **レポート**: どのファイルの・どこを・何から何に変えたか（Markdown と Excel）

## すぐ使う

1. clone する
2. **Windows**: `setup.cmd` をダブルクリック ／ **macOS・Linux**: `./setup.sh`
3. サンプルで試す

```bash
python samples/make_samples.py                                        # 架空の資料と置換表を作る
office-replace samples/input --rules samples/rules.xlsx -r --dry-run  # 置換される箇所を確認（書き換えない）
office-replace samples/input --rules samples/rules.xlsx -r -o out     # out/ に書き出す
```

1 組だけなら置換表は不要です。

```bash
office-replace 資料フォルダ -o 出力 --from "サンプル商事" --to "〇〇商事" --target all
```

Office のインストールは不要です（ファイルを直接読み書きします）。

## 置換表

Excel・CSV（UTF-8 / Shift_JIS）・TSV・YAML のどれでも書けます。1 行目は列名です。

| 置換前 | 置換後 | 対象 | 完全一致 |
|---|---|---|---|
| サンプル商事 | 〇〇商事 | すべて | |
| 株式会社テスト*支店 | （支店名） | 文字列 | |
| 担当: ?田 | 担当: （担当者） | | |
| 集計 | 集計_2027 | シート名 | ○ |

- **対象**: `文字列`（既定）/ `シート名` / `ファイル名` / `すべて`。カンマ区切りで複数可
- **完全一致**: `○` のとき、セル・段落の文字列全体が一致する場合だけ置換
- 上の行から順に適用します（前の行の置換結果に次の行が当たることがあります）
- `-i` で英字の大文字・小文字を区別しない

## シート名の制約

置換後のシート名が次に当たる場合は、そのシートは変更せずエラーとしてレポートします（終了コード 1）。

- 31 文字を超える ／ `: \ / ? * [ ]` を含む ／ 先頭・末尾が `'` ／ 空 ／ `History`（予約語） ／ 同じブックに同名のシートがある

シート名を変えたときは、数式・名前の定義・グラフの参照（`'旧名'!A1`）も新しい名前に直します。

## オプション

| オプション | 意味 |
|---|---|
| `-o DIR` | 出力フォルダ（入力フォルダの中は不可） |
| `-r` | サブフォルダも対象（出力にも同じ構成で書き出す） |
| `--dry-run` | 書き換えずにレポートだけ（`--report FILE.md` で保存） |
| `--copy-all` | 置換の無いファイルも出力フォルダにコピー（フォルダ一式を作るとき） |
| `--include-masters` | PowerPoint のスライドマスター・レイアウトも対象 |
| `--regex` / `-i` / `--whole` | 正規表現 / 大文字小文字を区別しない / 全体一致（`--from` のとき） |

終了コード: `0` 正常 ／ `1` エラーのあったファイルあり ／ `2` 引数・置換表の誤り ／ `3` 実行時エラー

## 対象外

- 古い形式（.xls / .doc / .ppt）: レポートに一覧を出します。新しい形式で保存し直してください
- パスワード付きのファイル: 開けないためエラーとして報告します
- Excel の数式の中の文字列・セルのコメント・ヘッダー／フッター、Word の変更履歴の削除部分、SmartArt
- 埋め込まれた別のファイル（Excel の中の Word など）

## VBA 版

Python を入れられない PC 向けに、VBA の参考実装を `vba/` に置いています（**未検証**。違いは [vba/README.md](vba/README.md)）。

## 開発

```bash
./setup.sh                    # Windows: setup.cmd
ruff check . && ruff format --check . && pytest
```

構成: `rules.py`（置換表・ワイルドカード）→ `engine.py`（フォルダの走査・出力）→ `processors.py`（Excel / Word / PowerPoint）→
`textruns.py`（書式の切れ目をまたぐ置換）/ `ooxml.py`（zip と XML の読み書き）→ `report.py`
