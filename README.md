# office-replace

Excel / Word / PowerPoint のファイルを、置換表に従って **まとめて置換** するツールです。
資料の使い回しで社名・担当者名・年度を差し替えるときや、提出前に固有名を伏せるときに使います。

- **対象**: セルの文字列・セルのコメント・図形（テキストボックス）・グラフのタイトル・ヘッダー／フッター（`&P` などの書式コードは変えない）・テーブルの列名（Excel）／本文・表・ヘッダー・フッター・脚注・コメント・テキストボックス・グラフ（Word）／
  スライドの図形・表・ノート・グラフ・コメント（PowerPoint）／**シート名**／**ファイル名**
- **見えにくい場所も置換**: 文書のプロパティ（タイトル・件名・作成者・キーワード・コメント・最終更新者・会社・管理者）、
  グラフに保存されている項目名・系列名、コメントの作成者名。置換したセルのふりがなは外す（元の読みが残らないように）
- **残りの確認**: 書き出したファイルの中を調べ、置換前の文字列が残っていればレポートに理由と対処を出し、終了コード 1 にする
- **ワイルドカード**: `*`（0 文字以上。Excel と同じくできるだけ長く一致）と `?`（1 文字）。`~*` `~?` で記号そのもの。`--regex` で正規表現
- **安全**: 元のファイルは書き換えず、別のフォルダに出力。`--dry-run` で置換される箇所だけを確認できる
- **書式を保つ**: 書式の切れ目をまたぐ文字列も置換し、置換した範囲の外の書式は変えない。画像・マクロなど他の部品はそのまま
- **レポート**: どのファイルの・どこを・何から何に変えたか（Markdown と Excel）。出力フォルダの外に置く（`--mask-report` で置換前を伏せる）

> **変更点（0.2.0・破壊的変更）**: 置換前の文字列が残ると終了コード 1、`*` が最長一致、レポートの場所が出力フォルダの外に。
> 詳しくは [CHANGELOG.md](CHANGELOG.md)

## すぐ使う

Python 3.12 以上と Git が要ります。

1. clone する
2. **Windows**: `setup.cmd` をダブルクリック ／ **macOS・Linux・Git Bash**: `./setup.sh`（Python 3.12 以上を `python3` → `python` → `py -3` の順に探し、無ければ止まります）
3. サンプルで試す

```bash
python samples/make_samples.py                                        # 架空の資料と置換表を作る
office-replace samples/input --rules samples/rules.xlsx -r --dry-run  # 置換される箇所を確認（書き換えない）
office-replace samples/input --rules samples/rules.xlsx -r -o out     # out/ に書き出す（レポートは out_report/）
```

1 組だけなら置換表は不要です。

```bash
office-replace 資料フォルダ -o 出力 --from "サンプル商事" --to "〇〇商事" --target all
```

Office のインストールは不要です（ファイルを直接読み書きします）。

## 置換表

Excel・CSV（UTF-8 / Shift_JIS）・TSV・YAML のどれでも書けます。1 行目は列名です。

| 置換前 | 置換後 | 対象 | 完全一致 |
|---|---|---|---|
| サンプル商事 | 〇〇商事 | すべて | |
| 株式会社テスト*支店 | （支店名） | 文字列 | |
| 担当: ?田 | 担当: （担当者） | | |
| 集計 | 集計_2027 | シート名 | ○ |

- **対象**: `文字列`（既定）/ `シート名` / `ファイル名` / `数式`（Excel の数式の中の文字列）/ `すべて`。カンマ区切りで複数可
  - `すべて` は 文字列・シート名・ファイル名。`数式` は数式を書き換えるので、明示したときだけ（下の「数式の中の文字列」）
- **完全一致**: `○` のとき、セル・段落の文字列全体が一致する場合だけ置換
- 上の行から順に適用します（前の行の置換結果に次の行が当たることがあります）
- `-i` で英字の大文字・小文字を区別しない
- `*` は Excel の検索と同じく **できるだけ長く** 一致します（`見積*` → `御見積` で「見積書A」は「御見積」）
  - ただし段落・セル内の改行（Word の Shift+Enter・PowerPoint の段落内の改行・Excel のセル内の改行を含む）とタブはまたぎません（`*` も `?` も改行・タブの文字には一致せず、置換前の普通の文字も、改行・タブをはさんだ文字列には一致しません。`--regex` のときは書いた正規表現のとおり）。また同じ置換前の 2 か所目（`*` より前の部分が次に出てくる位置）もまたがず、別々に置換します
    （`株式会社*支店` → `X` で「株式会社A支店と株式会社B支店」は「XとX」。間の「と」は消えません）
  - **Excel と違う点**: `*` は `*` より前の部分（頭）が出てくる位置をまたがないため、頭の文字が続くと Excel より後ろから一致します。
    `A*B` → `X` で「AAB」は、Excel では全体が「X」になりますが、このツールでは「AX」です（2 文字目の「A」から一致）。
    頭が続く文字列を置換するときは、`--dry-run` で置換される箇所を確かめてください（この仕様は変えません）
  - `*` の一致が 60 文字を超えたときは、意図しない範囲かもしれないので警告をレポートの「エラー・注意」に出します（置換はします。終了コードは変わりません）
- Excel の置換表は、セルの **表示どおり** の文字列で読みます（表示形式 `000` の `1` は `001`）。CSV のセル内の改行もそのまま読みます
- YAML の置換表は、値を **書いたとおりの文字列** で読みます（`0123` は「0123」、`no`・`yes` は「no」「yes」、`1.50` は「1.50」、`2026-01-01` は「2026-01-01」）。
  YAML の数値・真偽値・日付への変換はしません。値が空か `~`・`null` のときは空（置換後なら削除）です。`対象` はリスト（`[text, sheet]`）でも書けます

```yaml
rules:
  - 置換前: 0123      # 数値ではなく「0123」
    置換後: no        # 真偽値ではなく「no」
    対象: [文字列, シート名]
```

## テーブル（Excel の「テーブルとして書式設定」）

見出しのセルを置換したときは、テーブルの定義の列名も同じに直します（食い違うと Excel で開いたときに「修復」になるため）。
列名を使う数式・名前の定義（構造化参照 `テーブル1[旧列名]`・`テーブル1[[#見出し],[旧列名]]` など）も新しい列名に直します。
置換で同じテーブルに同じ列名が 2 つできるときはエラー（終了コード 1）としてレポートし、**そのファイルは出力しません**
（列名が重複したファイルは Excel で開くと「修復」になるため）。ほかのファイルは続けて処理します。

## Excel のヘッダー・フッター

印刷のヘッダー・フッターの文字列には、位置（`&L` `&C` `&R`）・ページ番号（`&P` `&N`）・日付（`&D` `&T`）・ファイル名とシート名（`&F` `&A`）・
フォント（`&"ＭＳ ゴシック,太字"`）・文字の大きさ（`&12`）・色（`&KFF0000`）などの **書式コード** が入っています。

- 書式コードは変えず、その間の文字だけを置換します（`P` → `Q` でも `&P` のページ番号はそのまま）
- 一致は書式コードをまたぎません（`社外秘*` の `*` は、後ろの `&R&P` まで広がりません）
- 文字の `&` はファイルの中では `&&` です。置換前・置換後には `&` のまま書きます（置換後の `&` は `&&` にして書き出すので、書式コードとして読まれません）
- 完全一致（`○` / `--whole`）は、書式コードを含むヘッダー・フッターの全体で見るので、ふつうは当たりません（当たらずに残れば「残っている文字列」に出ます）
- 残りの確認も、書式コードを除いた文字だけを調べます

## 数式の中の文字列

`="サンプル商事"&"様"` のような数式の中の文字列は、既定では置換しません（残りとしてレポートに出ます）。
対象に `数式`（`--target text,formula`）を指定すると、数式の `"…"` の中だけを置換します（セル参照・関数名・シート名は変えません）。
置換した数式の計算結果（保存されている値）は消し、ブックを開いたときに計算し直すようにします。

## シート名の制約

置換後のシート名が次に当たる場合は、そのシートは変更せずエラーとしてレポートします（終了コード 1）。

- 31 文字を超える ／ `: \ / ? * [ ]` を含む ／ 先頭・末尾が `'` ／ 空 ／ `History`（予約語） ／ 同じブックに同名のシートがある

シート名を変えたときは、そのシートを指す次の参照（`旧名!A1` や `'旧 名'!A1`）も新しい名前に直します。

- 数式・名前の定義・グラフの参照
- 入力規則（リストの元の値など）・条件付き書式の数式（Excel 2010 以降の拡張の部分も）
- ブックの中へのハイパーリンク・ピボットテーブルの元データのシート名・文書のプロパティのシート名の一覧
- 複数シートをまとめた参照（3D 参照 `SUM(集計:別!A1)`）は両端のシート名をそれぞれ直します（`'集計:新名'!A1`）
- 外部のブックの参照（`[1]集計!A1`）と、数式の文字列（`INDIRECT("集計!A1")`）の中は書き換えません

## 残っている文字列の注意

固有名を伏せる目的で使うときのために、書き出したファイルのすべての XML（埋め込まれた Excel / Word / PowerPoint の中も）を調べ、
置換前の文字列がまだあれば、レポートの「残っている文字列（注意）」とレポートの Excel の「残り」シートに出します（種類 `replace.leftover`）。

- 例: 数式の中の文字列（`="サンプル商事"&"様"`）、変更履歴の作成者、グラフの元データの埋め込みブック
- 残りがあると **終了コード 1** です（0.2.0 から）。以前どおり 0 にしたいときは `--allow-leftover` を付けます
- レポートの「理由」に、残った理由と対処を書きます（例: 数式の中の文字列 → `--target formula`、シート名（`xl/workbook.xml` の `sheet@name`）や数式の中のシート名の参照（場所が `f（シート名の参照）` など）→ `--target sheet`、ピボットのキャッシュ → Excel で更新、埋め込みのブック → 元のアプリで直す）
- 調べるのは、対象に「文字列」を含み、正規表現（`--regex`）でないルールだけです。置換後に置換前が含まれるルール（`集計` → `集計_2027` など）は調べません
- 出力ファイルの名前（出力フォルダからの相対パス。フォルダ名を含む）に置換前が残っていても「残り」に出します（部品は `（出力ファイル名） <名前>`）。ファイル名は `--target file` で置換できます。対象に「文字列」か「ファイル名」を含むルールで調べます
  - **フォルダ名は置換しません**（`--target file` でも変わるのはファイル名だけ）。`-r` で置換前を含むフォルダ（`資料/サンプル商事/見積.xlsx` など）があると、直せないまま「残り」になり **終了コード 1** です。出力フォルダでフォルダの名前を変えてから共有するか、確かめたうえで `--allow-leftover` を付けます
- 画像の中の文字や、XML でない部品（マクロなど）は調べません
- 調べるのは XML の **文字**（セル・段落・図形の文字など）と、**意味のある属性** だけです。意味のある属性は、利用者が付けた名前や画面に出る文字を持つもの:
  シート名・名前の定義・テーブル名と列名・集計行の文字・図形や画像の名前と代替テキスト・変更履歴やコメントの作成者・入力規則のメッセージ・リンクのヒントと表示文字・
  ピボットの項目名・オートフィルターの条件・Word のコンテンツコントロールのタイトルとタグ・外部へのリンク先（ファイルのパス・URL）など
  - 色（`FF5050`）・大きさ・座標・ID・番号・書式などの構造用の属性、図形の位置（行・列・オフセット）、文書のプロパティの統計（ページ数・編集時間・版数など）は調べません。
    `--from 50` のような数字の置換で、テーマの色や図形の座標に当たって終了コード 1 にならないように
- 文書のプロパティの日付（作成日時・更新日時・印刷日時・ユーザー設定の日付）と、Excel の共有文字列の番号は調べません（文字列ではない値のため。年度の置換 `2025` → `2026` で毎回当たらないように）
- Excel の数値のセル・数式の計算結果に残ったものは、場所を `v（数値など）` / `v（数式の結果）` と出します（このツールは数値・計算結果を書き換えません）
- Excel の数値のセル（数値の計算結果を含む）は、値の **全体** が置換前に一致するときだけ数えます（`202` の置換で `2025` は数えません）。部分一致も数えるのは文字列のセル・文字列の計算結果だけです

## オプション

| オプション | 意味 |
|---|---|
| `--rules FILE` | 置換表（.xlsx / .csv / .tsv / .yaml。上の「置換表」） |
| `--from 置換前` / `--to 置換後` | 1 組だけ置換するとき（置換表の代わり。`--rules` とどちらか一方）。`--to` を省くと置換後は空（削除） |
| `--target 対象` | `--from` の対象: `text`（既定）/ `sheet` / `file` / `formula` / `all`（text・sheet・file）。カンマ区切りで複数可 |
| `-o DIR` | 出力フォルダ（入力フォルダの中は不可。入力が 1 ファイルのときは、**そのファイルのあるフォルダの中も不可**。例: `office-replace docs/見積.xlsx -o docs/out` は誤り、`-o out` などフォルダの外に）。空のフォルダを推奨（下の「出力フォルダの前回の残り」） |
| `-r` | サブフォルダも対象（出力にも同じ構成で書き出す） |
| `--dry-run` | 書き換えずにレポートだけ（`--report FILE.md` で保存） |
| `--report FILE.md` | レポートの場所（同じ名前の .xlsx も作る）。既定は出力フォルダと同じ階層の `<出力フォルダ名>_report/` |
| `--mask-report` | レポートの置換前の文字列を「（伏せ字）」にし、ファイル名・場所・エラー文は置換後の名前で出す（完全一致のルールも、伏せ字では部分一致で当てる） |
| `--allow-leftover` | 置換前の文字列が残っていても終了コード 0（レポートには出す） |
| `--copy-all` | 置換の無いファイルも出力フォルダにコピー（フォルダ一式を作るとき） |
| `--include-masters` | PowerPoint のスライドマスター・レイアウトも対象 |
| `--regex` / `-i` / `--whole` | 正規表現 / 大文字小文字を区別しない / 全体一致（`--from` のとき）。`--regex`・`-i` は置換表のすべての行にも効きます |
| `--log-level LEVEL` | ログの細かさ（`DEBUG` / `INFO` / `WARNING`（既定）/ `ERROR`） |
| `--version` | 版を表示する |
| `--max-unzip-mb` / `--max-entries` / `--max-ratio` | zip 爆弾対策の上限（1 ファイルの展開後の合計 MB・部品の数・部品の圧縮率）。既定 2048 / 10000 / 200（圧縮率は 1MB を超える部品だけ見る）。超えるファイルはエラー |

`--to`・`--target`・`--whole` は `--from` と組で使います。`--rules` と一緒に付けても使われず、警告を出します（置換後・対象・完全一致は置換表の列で指定します）。

終了コード: `0` 正常 ／ `1` エラーのあったファイルあり、または置換前の文字列が残っている（`--allow-leftover` で 0）／ `2` 引数・置換表の誤り ／ `3` 実行時エラー

1 ファイルの処理に失敗しても（壊れた XML など）、残りのファイルは続けて処理し、レポートは必ず書きます。失敗したファイルはレポートに「エラー」として出し、終了コードは `1` です。

## レポートの扱い（注意）

レポートには **置換前の文字列（伏せたい固有名）がそのまま入ります**。そのため既定では出力フォルダの外
（`-o out` なら `out_report/`）に置きます。出力フォルダだけを共有してください。

- レポートも渡すときは `--mask-report` を付けます（置換前は「（伏せ字）」、ファイル名・シート名は置換後の名前になります）
- `--report` で出力フォルダの中を指定したときは警告を出します

### 出力フォルダの前回の残り

同じ出力フォルダで実行し直すと、前回書き出したファイルは消しません（今回置換の無かったファイルや、置換表を変えて名前が変わったファイルの前回の出力が残ります）。
残ったファイルには置換前の文字列が入っていることがあるので、今回書き出していないファイルが出力フォルダにあれば、件数と名前（先頭 5 件）を標準エラーに警告します（終了コードは変えません）。
共有する前に確認するか、空の出力フォルダで実行し直してください。

## 対象外

- 古い形式（.xls / .doc / .ppt）: レポートに一覧を出します。新しい形式で保存し直してください
- パスワード付きのファイル: 開けないためエラーとして報告します
- Excel の数式の中の文字列（`数式` を対象にしたときは置換）、ピボットテーブルのキャッシュ、Word の変更履歴の削除部分と作成者、SmartArt
- 埋め込まれた別のファイル（Excel の中の Word、グラフの元データのブックなど）。残っていれば「残っている文字列」に出ます

./setup.sh                        # Windows: setup.cmd（Git Bash なら ./setup.sh でも可）
python scripts/verify_gates.py    # CI と同じゲート（lint・フォーマット・テスト・サンプルの実行・bandit・pip-audit）
python scripts/verify_gates.py --quick   # = ruff check . && ruff format --check . && pytest

- 変更を CHANGELOG.md の「未リリース」に書いたら、`pyproject.toml` の版は `.devN` にします（テストで確かめます）

- 依存の版は `constraints.txt` でそろえます（`pip install -c constraints.txt -e ".[dev]"`。GitHub Actions の deps-lock が作る）
- CI: Linux と Windows のテスト、LibreOffice で置換後のサンプルを開けるか（PDF に変換）、bandit・pip-audit（ハッシュを確かめて入れた依存で）

### ハッシュを確かめて入れる

`constraints.txt` は版だけを固定します（ハッシュを入れると `pip install -e .` と git の依存が入らなくなるため）。
配布物の改ざんも確かめたいときは、実行時の依存をハッシュ付きの `requirements-hashes.txt`（deps-lock が `constraints.txt` と同じ版で作る）から入れます。

```bash
pip install --require-hashes -r requirements-hashes.txt
pip install --no-deps -e . "devtools-common @ git+https://github.com/shoyo-maya-bot/devtools-common.git@<pyproject.toml の SHA>"
pip check
```

`setup.sh` / `setup.cmd` は今までどおり `constraints.txt` を使います（開発用の依存も入れるため）。

構成: `rules.py`（置換表・ワイルドカード）→ `engine.py`（フォルダの走査・出力）→ `processors/`（形式ごと: `spreadsheet.py` Excel・`formula.py` 数式・`wordprocessing.py` Word・`presentation.py` PowerPoint・`docprops.py` 文書のプロパティ）→
