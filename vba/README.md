# VBA 版（参考・未検証・サポート外）

> **参考・未検証・サポート外です。** 不具合の報告・修正の依頼は受け付けません。テストも CI もありません。
> Python 版で直した点（テーブルの列名・ワイルドカードの最長一致・残りの検出など）も、VBA 版には入っていません。

`OfficeReplace.bas` は、Python が使えない PC 向けの **参考実装** です。**動作は検証していません。**
正は Python 版（`office-replace` コマンド）です。使う前に、必ずコピーしたファイルで結果を確かめてください。

| 項目 | Python 版 | VBA 版 |
|---|---|---|
| 検証 | テストと CI で確認 | 未検証 |
| Office のインストール | 不要 | 必要（Excel・Word・PowerPoint を自動操作） |
| サブフォルダ | `-r` で対象 | 対象外 |
| 書式の保持 | ランをまたいでも置換範囲の外は保つ | ワイルドカードを使うと段落単位で書式が崩れることがある |
| 置換箇所の記録 | セル番地まで（Markdown / Excel） | セルは記録しない（図形・シート名・スライドのみ） |
| 試行（書き換えない確認） | `--dry-run` | なし |
| シート名の参照の更新 | 数式・名前の定義・グラフを XML で更新 | Excel が自動で追従 |
| 置換前の文字列の残り | 調べてレポートに出し、終了コード 1 | 調べない |
| サポート | あり（Issue で受け付ける） | **なし** |

使い方はファイル先頭のコメントを参照してください。マクロを含むブック（.xlsm）の配布は、所属組織のルールに従ってください。
